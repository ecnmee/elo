# Contributing

This repository is a **read-only split** of the
[`ecnmee/elo-monorepo`](https://github.com/ecnmee/elo-monorepo) development
monorepo. It does not accept direct pull requests to the core.

## Where to contribute

- **Bugs, features, core changes:** open an issue or PR on
  [`ecnmee/elo-monorepo`](https://github.com/ecnmee/elo-monorepo).
- **Architecture documentation** (ADR-001 Architecture, ADR-002 Philosophy,
  ADR-003 Language) lives in the monorepo's `docs/adr/` and governs every
  contribution, see the monorepo's `CONTRIBUTING.md` for the full
  contribution constitution: rules for PRs, feature acceptance criteria,
  and quality gates.

## Reporting issues specific to this package

If you find an issue specifically with how the package installs or behaves
via Composer (as opposed to a core architectural concern), feel free to
open it here, it will be triaged and, if needed, moved to the monorepo.
