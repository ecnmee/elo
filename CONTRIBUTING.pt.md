# Contribuir

Este repositório é uma **cópia só de leitura** gerada a partir do monorepo
de desenvolvimento [`ecnmee/elo-monorepo`](https://github.com/ecnmee/elo-monorepo).
Não aceita pull requests directos ao core.

## Onde contribuir

- **Bugs, funcionalidades, alterações ao core:** abrir uma issue ou PR no
  [`ecnmee/elo-monorepo`](https://github.com/ecnmee/elo-monorepo).
- **Documentação de arquitectura** (ADR-001 Arquitectura, ADR-002 Filosofia,
  ADR-003 Linguagem) vive em `docs/adr/` do monorepo e rege toda a
  contribuição, ver o `CONTRIBUTING.md` do monorepo para a constituição
  completa de contribuição: regras para PRs, critérios de aceitação de
  funcionalidades, e critérios de qualidade.

## Reportar problemas específicos deste pacote

Se encontrares um problema específico de como o pacote se instala ou
comporta via Composer (em vez de uma questão arquitectural do core), podes
abrir aqui, será triado e, se necessário, movido para o monorepo.
